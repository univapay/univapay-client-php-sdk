
# Generic Metadata Value

Allowed values for metadata properties.

## Data Type

`string|float|bool`

## Cases

| Type |
|  --- |
| `string` |
| `float` |
| `bool` |

## string

### Initialization Code

#### Example

```php
$value = 'sale';
```

## float

### Initialization Code

#### Example

```php
$value = 10;
```

## bool

### Initialization Code

#### Example

```php
$value = true;
```
